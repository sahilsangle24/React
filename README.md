## Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- npm
- Git and GitHub

## How to Run a Project

1. Clone this repository:

   ```bash
   git clone https://github.com/sahilsangle24/React.git
   ```

2. Open the required project folder:

   ```bash
   cd React/firstReactApp
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
